# Portfólio de automações e agentes de IA

Os projetos desta pasta usam **somente dados fictícios** para serem demonstrados publicamente.

## Demonstração 1: monitor de solicitações

`monitor_inbox/` transforma eventos JSON sintéticos em um CSV com checagem de duplicidade por protocolo. É uma base para aprender extração, validação, idempotência, persistência e testes, **não** acessa caixas de e-mail ou ferramentas corporativas.
